خريطة الدروس

المستوى الأول: مقدمة البرمجة

البرمجة هي كتابة أوامر وتعليمات للكمبيوتر لكي ينفذ مهمة. لغة C++ لغة قوية تُستخدم في تطوير البرامج والألعاب والأنظمة. الكمبيوتر ينفذ التعليمات بدقة، لذلك يجب أن تكون الأوامر مرتبة.

مثال

// هذه ملاحظة داخل كود C++
// سنتعلم كتابة الأوامر في الدرس التالي
سؤال الدرس: ما البرمجة؟

الدرس الثاني: أول برنامج C++

نستخدم مكتبة iostream للطباعة والإدخال. الدالة main هي نقطة بداية تنفيذ البرنامج، والأقواس تحدد جسم الدالة.

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!";
    return 0;
}

شرح: cout تطبع النص، والفاصلة المنقوطة ; تنهي التعليمة.

سؤال: من أين يبدأ البرنامج عادةً؟

الدرس الثالث: المتغيرات

المتغير مكان مسمى في الذاكرة نخزن فيه قيمة. نحدد نوع المتغير ثم اسمه ثم قيمته الابتدائية.

int score = 20;
cout << score;

هنا أنشأنا متغيرًا اسمه score وقيمته 20.

سؤال: ما قيمة score؟

الدرس الرابع: أنواع البيانات

كل متغير له نوع يحدد شكل البيانات التي يخزنها. أشهر الأنواع: int عدد صحيح، double عدد عشري، char حرف واحد، و string نص.

#include <string>
int age = 16;
double average = 92.5;
char grade = 'A';
string name = "Ahmed";
سؤال: أي نوع يناسب الرقم 4.75؟

المستوى الثاني: العمليات الحسابية

يمكنك إجراء عمليات حسابية داخل C++: الجمع +، الطرح -، الضرب *، القسمة /، وباقي القسمة % للأعداد الصحيحة.

int a = 8;
int b = 3;
cout << a + b; // 11
cout << a % b; // 2
سؤال: ما ناتج 8 * 3؟

الدرس السادس: الشروط if و else

تسمح الشروط للبرنامج باتخاذ قرار. إذا تحقق الشرط ينفذ جزء if، وإلا يمكن تنفيذ جزء else.

int mark = 75;
if (mark >= 50) {
    cout << "نجاح";
} else {
    cout << "حاول مرة أخرى";
}
سؤال: متى ينفذ كود if؟

المستوى الثالث: حلقات التكرار

تكرر الحلقة for مجموعة أوامر. تتكون عادة من قيمة بداية، وشرط استمرار، وتحديث للعداد.

for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}

ستطبع الأرقام من 1 إلى 5.

سؤال: كم مرة تتكرر الحلقة؟

الدرس الثامن: الحلقات المتداخلة

يمكن وضع حلقة داخل حلقة أخرى. في كل دورة من الحلقة الخارجية، تنفذ الحلقة الداخلية دوراتها كاملة.

for (int row = 1; row <= 2; row++) {
    for (int col = 1; col <= 3; col++) {
        cout << "*";
    }
    cout << endl;
}
سؤال: كم نجمة تطبع في كل سطر؟

المستوى الرابع: الدوال

الدالة مجموعة أوامر لها اسم، ويمكن استدعاؤها عند الحاجة. تساعدنا على تنظيم البرنامج وإعادة استخدام الكود.

void greet() {
    cout << "Welcome!";
}

int main() {
    greet();
    return 0;
}
سؤال: لماذا نستخدم الدوال؟

الدرس العاشر: تحدي المراجعة

جمعت هنا أهم الأفكار: main بداية البرنامج، cout للطباعة، المتغيرات لتخزين القيم، if لاتخاذ القرار، for للتكرار، والدوال لتنظيم الأوامر.

#include <iostream>
using namespace std;
int main() {
    int number = 5;
    if (number > 0) {
        cout << "Positive";
    }
    return 0;
}
التحدي الأخير: ما وظيفة return 0 في نهاية main غالبًا؟

المستوى 11: البرمجة كائنية التوجه OOP

البرمجة كائنية التوجه طريقة لتنظيم البرنامج حول كائنات تجمع البيانات والوظائف التي تتعامل معها. من أهم أفكارها: التغليف والوراثة وتعدد الأشكال.

مثال تطبيقي

class Player {
public:
    int score = 0;
    void addPoint() { score++; }
};

int main() {
    Player p;
    p.addPoint();
    cout << p.score;
}

تذكّر: الكائنات تجمع البيانات والسلوك في وحدة منظمة.

اختبر فهمك: ما الفكرة الأساسية في OOP؟

المستوى 12: Classes و Objects

class هو القالب الذي نحدد فيه الخصائص والدوال، أما object فهو نسخة فعلية من هذا القالب. يمكن إنشاء أكثر من كائن من نفس الفئة.

مثال تطبيقي

class Car {
public:
    string color;
};

int main() {
    Car myCar;
    myCar.color = "Red";
    cout << myCar.color;
}

تذكّر: الـ Class هو التصميم، والـ Object هو الكائن الذي أنشأناه منه.

اختبر فهمك: ما الفرق بين Class و Object؟

المستوى 13: Inheritance و Polymorphism

الوراثة تسمح لفئة جديدة باستخدام خصائص ودوال فئة أخرى. تعدد الأشكال يسمح باستدعاء واجهة واحدة والحصول على سلوك يختلف حسب نوع الكائن.

مثال تطبيقي

class Animal {
public:
    void eat() { cout << "Eating"; }
};

class Cat : public Animal {
};

int main() {
    Cat c;
    c.eat();
}

تذكّر: الوراثة تقلل التكرار وتساعد على بناء علاقات بين الفئات.

اختبر فهمك: ماذا تتيح الوراثة؟

المستوى 14: التعامل مع الملفات

تتيح مكتبة fstream قراءة الملفات والكتابة فيها. نستخدم ofstream للكتابة و ifstream للقراءة، ويجب التأكد من فتح الملف قبل التعامل معه.

مثال تطبيقي

#include <fstream>
using namespace std;

int main() {
    ofstream file("notes.txt");
    file << "My first file";
    file.close();
}

تذكّر: ofstream مخصص لإنشاء الملفات والكتابة فيها.

اختبر فهمك: أي نوع يُستخدم عادةً للكتابة في ملف؟

المستوى 15: Templates

تسمح القوالب Templates بكتابة دوال أو فئات تعمل مع أنواع بيانات مختلفة دون تكرار الكود.

مثال تطبيقي

template <typename T>
T bigger(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << bigger(4, 9);
}

تذكّر: القوالب تجعل الكود أكثر مرونة وإعادة استخدام.

اختبر فهمك: ما فائدة Templates؟

المستوى 16: STL وهياكل البيانات

مكتبة STL توفر أدوات جاهزة مثل vector و stack و queue و map. الـ vector مصفوفة ديناميكية يمكن أن يتغير حجمها أثناء التشغيل.

مثال تطبيقي

#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {3, 6, 9};
    numbers.push_back(12);
    cout << numbers.size();
}

تذكّر: vector يتوسع أو ينكمش حسب العناصر التي تضيفها أو تحذفها.

اختبر فهمك: ما الذي يميز vector عن المصفوفة التقليدية؟

المستوى 17: Algorithms

توفر مكتبة algorithm خوارزميات جاهزة للفرز والبحث وغيرها. استخدام الخوارزميات الجاهزة يقلل الأخطاء ويوفر الوقت.

مثال تطبيقي

#include <algorithm>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {5, 1, 4};
    sort(v.begin(), v.end());
    cout << v[0];
}

تذكّر: sort ترتب العناصر تصاعديًا افتراضيًا عند استخدام هذا المثال.

اختبر فهمك: ما وظيفة sort؟

المستوى 18: مشروع التخرج والمراجعة

وصلت إلى مشروعك الأول! اجمع ما تعلمته في برنامج بسيط لإدارة درجات الطلاب: خزّن الدرجات، احسب المتوسط، واستخدم شرطًا لتحديد التقدير. خطط قبل كتابة الكود واختبر الحالات المختلفة.

مثال تطبيقي

#include <iostream>
using namespace std;

int main() {
    int a = 80, b = 90, c = 70;
    double avg = (a + b + c) / 3.0;
    cout << "Average: " << avg << endl;
    if (avg >= 85) cout << "Excellent";
    else cout << "Keep practicing";
    return 0;
}

تذكّر: التخطيط وتقسيم المشروع إلى مهام صغيرة يجعل التنفيذ أسهل.

اختبر فهمك: ما الخطوة الأفضل قبل كتابة مشروع كبير؟

المستوى 19: الدوال المتقدمة

الدوال تساعدنا على تقسيم البرنامج إلى أجزاء صغيرة قابلة لإعادة الاستخدام. يمكن للدالة استقبال معاملات وإرجاع قيمة باستخدام return.

مثال

int square(int number) {
    return number * number;
}
// square(4) ترجع 16
سؤال الدرس: ما الكلمة المستخدمة لإرجاع قيمة من الدالة؟

المستوى 20: النطاق ومدة حياة المتغيرات

المتغير المحلي يُعرّف داخل دالة ولا يمكن استخدامه خارجها. أما المتغير العام فيُعرّف خارج الدوال ويمكن الوصول إليه وفق قواعد النطاق. يُفضّل تقليل المتغيرات العامة.

مثال

int total = 0; // متغير عام

void add() {
    int step = 1; // متغير محلي
    total += step;
}
سؤال الدرس: أين يمكن استخدام المتغير المحلي المعرّف داخل دالة؟

المستوى 21: المصفوفات متعددة الأبعاد

المصفوفة ثنائية الأبعاد تشبه جدولًا من الصفوف والأعمدة. نستخدم فهرسين للوصول إلى العنصر: الأول للصف والثاني للعمود، وتبدأ الفهارس من الصفر.

مثال

int marks[2][3] = {
    {10, 20, 30},
    {15, 25, 35}
};
cout << marks[1][2]; // 35
سؤال الدرس: ما العنصر الذي يشير إليه marks[1][2]؟

المستوى 22: التعامل مع النصوص string

نوع string يخزن النصوص، ويمكن دمج النصوص باستخدام + ومعرفة طول النص باستخدام length(). للوصول إلى حرف نستخدم الفهرس الذي يبدأ من صفر.

مثال

string name = "Ahmed";
cout << name.length(); // 5
cout << name[0]; // A
سؤال الدرس: ما ناتج name[0] في النص Ahmed؟

المستوى 23: المؤشرات Pointers

المؤشر متغير يخزن عنوان متغير آخر في الذاكرة. الرمز & للحصول على العنوان، والرمز * للوصول إلى القيمة الموجودة في ذلك العنوان. استخدم المؤشرات بحذر وتأكد من تهيئتها قبل استخدامها.

مثال

int score = 90;
int* ptr = &score;
cout << *ptr; // 90
سؤال الدرس: ماذا يخزن المؤشر ptr؟

المستوى 24: المراجع References

المرجع اسم بديل لمتغير موجود. نكتبه باستخدام & عند التعريف، ويجب ربطه بمتغير عند إنشائه. تعديل المرجع يغيّر قيمة المتغير الأصلي.

مثال

int age = 16;
int& ref = age;
ref = 17;
// age أصبحت 17
سؤال الدرس: ماذا يحدث عند تعديل ref؟

المستوى 25: Constructors و Destructors

الـ Constructor دالة خاصة تُستدعى عند إنشاء كائن لتهيئة بياناته. والـ Destructor يُستدعى عند انتهاء عمر الكائن لتنفيذ التنظيف اللازم.

مثال

class Player {
public:
    Player() { cout << "Created"; }
    ~Player() { cout << "Ended"; }
};
سؤال الدرس: متى يُستدعى Constructor عادةً؟

المستوى 26: التغليف Encapsulation

التغليف يجمع البيانات والدوال داخل class، ويحدد صلاحية الوصول باستخدام public وprivate وprotected. يساعد ذلك على حماية البيانات والتحكم في تعديلها.

مثال

class BankAccount {
private:
    double balance = 0;
public:
    void deposit(double x) {
        if (x > 0) balance += x;
    }
};
سؤال الدرس: أي محدد يمنع الوصول المباشر من خارج الكلاس؟

المستوى 27: الوراثة وتعدد الأشكال

الوراثة تسمح لكلاس جديد باستخدام خصائص ودوال كلاس أساسي. وتعدد الأشكال يسمح باستدعاء تنفيذ مناسب للدالة عند استخدام virtual مع إعادة تعريفها في الكلاس المشتق.

مثال

class Animal {
public:
    virtual void sound() { cout << "..."; }
};
class Cat : public Animal {
public:
    void sound() override { cout << "Meow"; }
};
سؤال الدرس: ما فائدة virtual في المثال؟

المستوى 28: معالجة الأخطاء والاستثناءات

نستخدم try لتحديد الجزء الذي قد ينتج عنه استثناء، وthrow لإطلاق الاستثناء، وcatch للتعامل معه. تساعد هذه الأدوات على جعل البرنامج أكثر قدرة على التعامل مع الحالات غير المتوقعة.

مثال

try {
    throw runtime_error("Problem");
} catch (const exception& e) {
    cout << e.what();
}
سؤال الدرس: أي جزء يستقبل الاستثناء ويتعامل معه؟

المستوى 29: Recursion وتحليل Big O

الاستدعاء الذاتي Recursion هو أن تستدعي الدالة نفسها، ويجب توفير حالة أساسية لإيقاف الاستدعاء. أما Big O فيصف كيف ينمو وقت التنفيذ أو استهلاك الموارد مع زيادة حجم المدخلات.

مثال

int factorial(int n) {
    if (n <= 1) return 1; // حالة أساسية
    return n * factorial(n - 1);
}
سؤال الدرس: لماذا نحتاج الحالة الأساسية في Recursion؟

المستوى 30: مشروع إدارة الطلاب

حان وقت تجميع ما تعلمته! صمّم برنامجًا بسيطًا لإدارة الطلاب. استخدم class لتمثيل الطالب، وvector لتخزين القائمة، ودوال للإضافة والبحث والعرض. ابدأ بنسخة صغيرة ثم طوّرها خطوة بخطوة.

مثال

struct Student {
    string name;
    int grade;
};
vector students;
students.push_back({"Ali", 95});
سؤال الدرس: ما البنية المناسبة لتخزين قائمة طلاب يتغير عددها؟
